## 3. 콘텐츠 제안

### ① 시세 허브: "2026 家教行情・時薪總整理"

- **이유**: 가격 계열 키워드 7개가 모두 1111의 시세 계산 도구 1페이지로 몰려 1위를 차지한다. KD는 0~21이다. EverydayTutor에는 이미 `/insights/korean-tutor-rates`, `/insights/taipei-math-tutor-rates` 같은 시세 글이 있다(단, 오디트 v2 P0 깨진 링크부터 수정).
- **URL**: `/insights/tutor-rates` (기존 과목별 시세 글들의 허브)
- **제목**: `2026 家教行情・時薪總整理｜國小到高中、各科目與縣市一次看｜每日家教`
- **메타 설명**: `家教時薪多少才合理？整理2026年全台國小、國中、高中各科家教行情與一對一費用，附各縣市比較與計算方式。`
- **목차**
  - H2 2026 家教時薪行情總表
    - H3 依年級：國小／國中／高中／大學
    - H3 依科目：數學・英文・理化・國文・鋼琴
  - H2 各縣市家教行情比較（台北・新北・台中・台南・高雄・新竹）
  - H2 一對一家教 vs 補習班 費用比較
  - H2 影響家教費用的5個因素
  - H2 家長與老師如何議價（常見問題）
- **내부 링크**: 과목별 시세 글(`/insights/korean-tutor-rates`, `/insights/taipei-math-tutor-rates`), 각 지역×과목 랜딩, 검색 페이지
- **데이터 출처 주의**: 사이트에 공개된 교사·학생 게시글에서 시세를 집계해 출처와 기준일을 밝힌다. 근거 없는 숫자는 쓰지 않는다.

### ② 과목 페이지 보강: 數學家教 / 英文家教

- `/tutors/mathematics`: 제목에 "數學家教"를 정확히 넣는다(예: `數學家教｜全台國小到高中數學家教老師搜尋｜每日家教`).
- 영어: 1,900+1,000 수요로 가장 크지만 KD가 26~33이다. 시세 허브와 지역 랜딩에서 내부 링크를 모아 순위를 끌어올린다.
- 목차 공통: H2 {과목}家教老師（最新） → H2 {과목}家教行情 → H2 依年級找{과목}家教 → H2 線上 vs 到府 → H2 常見問題

### ③ 가이드 글: "找家教怎麼找？5步驟避開地雷"

- **타깃**: 找家教, 家教怎麼找, 英文家教怎麼找, 家教平台, 家教網推薦
- **제목**: `家教怎麼找？2026找家教5步驟＋家教平台比較｜每日家教`
- **목차**: H2 先確認需求（科目・年級・預算） → H2 找家教的管道比較（家教網・社群・補習班） → H2 如何判斷家教老師適不適合（試教・學經歷） → H2 家教費用怎麼談 (→①) → H2 常見問題
- **주의**: 경쟁사를 깎아내리는 비교는 피하고, 일반적인 매칭 방식으로 비교한다.

### ④ 지역×과목 랜딩 보강

- 오디트 v2에서 얇은 콘텐츠 19건이 나왔다. 수요가 확인된 조합부터 보강한다: 台中×英文, 台南×數學, 高雄×英文, 新竹(전체).
- 템플릿에 해당 지역 시세(① 링크), 공개 게시글 수, 인근 지역 링크, FAQ를 추가한다.

### ⑤ 공급 측 가이드: "家教怎麼接？新手家教老師接案指南"

- **타깃**: 家教怎麼接 (260, KD 4)
- 교사 가입(`/signup`)으로 연결해 매칭 사이트의 공급 측을 늘린다.
