# PW Studio (`pwstudio.kr`) 키워드 갭 분석

- **대상**: `pwstudio.kr` (projectId `0aa884bf-1249-4a89-b8c9-e215f64bdb31`)
- **작성일**: 2026-10-05
- **데이터 출처**: OpenSEO MCP → DataForSEO Labs (Google, 대한민국 `2410` / `ko`). `find_serp_competitors`, `get_ranked_keywords`
- **조회 시점**: 2026-10-05 스냅샷. 검색량, KD, CPC는 DataForSEO 추정치다.
- **원본 데이터**: `docs/seo/data/2026-10-05-pwstudio-kr-kw-competitors.json`, `…-kw-gap-raw.json`
- **분석 한계**
  - **Google 데이터만 있다.** 한국 검색 시장은 네이버 비중이 크지만, OpenSEO(DataForSEO)는 네이버 검색량과 순위를 제공하지 않는다. 아래 검색량은 Google 기준이라 실제 수요보다 작게 잡힌다. 네이버 수요는 네이버 검색광고 키워드 도구로 별도 확인이 필요하다.
  - pwstudio.kr의 순위 키워드는 **0개**다(빈 결과).
  - `www.website.co.kr`은 API가 `website.co.kr` 하위 도메인 전체로 조회했다. 그래서 블로그 잡글(실업급여, 제주 맛집 등)이 섞여 있고, 이런 키워드는 제외했다.

## 1. 경쟁사 선정 근거

시드 키워드 10개(홈페이지 제작, 홈페이지 제작 업체·비용, 회사·소상공인 홈페이지 제작, 반응형, 랜딩페이지, 네이버·구글 검색 등록)로 SERP 경쟁 도메인을 조회했다. Wix·Canva·imweb 같은 DIY 빌더와 크몽(마켓플레이스), 네이버 블로그는 PW Studio(제작 대행)와 사업 모델이 달라 제외했다.

| 도메인 | 선정 이유 | 전체 순위 키워드 수 |
| --- | --- | ---: |
| `homepage.whois.co.kr` | 후이즈 홈페이지. 도메인과 홈페이지 제작을 묶어 판매한다는 점이 PW Studio의 "독립 도메인 세팅"과 같다. "홈페이지 제작" 3위 | 51 |
| `website.co.kr` | 웹 에이전시. "홈페이지 제작 비용", "단가표", 업종별 제작 블로그 글로 순위를 확보 | 345 (하위 도메인 포함) |

## 3. 콘텐츠 제안

### ① 가격 안내 페이지: "홈페이지 제작 비용 (2026 단가표)"

- **타깃**: 홈페이지 제작 비용, 홈페이지 제작 단가표 (합계 850, 둘 다 KD 0)
- **URL**: `/pricing` 또는 `/guide/homepage-cost`
- **제목**: `홈페이지 제작 비용 2026 단가표 | 소상공인·기업 공식 웹사이트 – 피터와웬디 스튜디오`
- **메타 설명**: `홈페이지 제작 비용이 궁금하신가요? 페이지 수·기능·도메인·유지관리별 실제 단가표와 견적 예시를 공개합니다. 네이버·구글 검색 등록 포함.`
- **목차**
  - H2 홈페이지 제작 비용, 무엇으로 결정될까?
    - H3 페이지 수와 디자인 수준
    - H3 반응형·예약·결제 등 기능
    - H3 도메인·호스팅·유지관리 비용
  - H2 피터와웬디 스튜디오 단가표 (실제 요금표)
  - H2 업체 유형별 견적 예시 (카페·병원·학원·소상공인)
  - H2 저렴한 제작과 정식 제작의 차이 (빌더 vs 대행)
  - H2 자주 묻는 질문 (추가 비용, 수정 횟수, 소유권)
- **내부 링크**: 메인 서비스, `/checkout`(결제 퍼널은 noindex 상태 유지), 검색 등록 서비스 소개, ② 가이드 글
- **주의**: 실제 요금을 그대로 공개해야 "단가표" 검색 의도를 충족한다.

### ② 가이드 글: "홈페이지 만드는 법 — 직접 만들기 vs 맡기기"

- **타깃**: 사이트 만드는법, 홈페이지 만드는 법·방법, 웹사이트 만드는법, 홈페이지 제작 방법 (합계 약 1,390)
- **제목**: `홈페이지 만드는 법 5단계 (2026) — 직접 만들기 vs 제작 맡기기 비교`
- **목차**
  - H2 1단계: 목적과 필요한 페이지 정하기
  - H2 2단계: 도메인 구입과 연결 (→ ⑤ 도메인 가이드로 링크)
  - H2 3단계: 제작 방식 고르기
    - H3 무료 빌더(Wix·imweb)로 직접 만들기
    - H3 제작 업체에 맡기기
    - H3 비교표: 비용·시간·검색 노출·소유권
  - H2 4단계: 네이버·구글 검색 등록
  - H2 5단계: 유지관리와 보안
  - H2 자주 묻는 질문
- **내부 링크**: ① 가격 페이지(행동 유도), ⑤ 도메인 가이드, 검색 등록 서비스

### ③ 서비스 랜딩: "기업·회사 홈페이지 제작" (장기)

- **타깃**: 기업 홈페이지 제작(390), 회사 홈페이지 제작(140), 기업 홈페이지 제작업체(90). CPC 11~15달러로 전환 가치가 가장 높다.
- KD가 46~67이라 신생 사이트는 상위권까지 시간이 걸린다. 포트폴리오 사례가 쌓인 뒤 집중한다.
- **제목**: `기업 홈페이지 제작 | 공식 웹사이트·독립 도메인·검색 등록 원스톱 – 피터와웬디 스튜디오`
- **목차**: H2 기업 홈페이지에 필요한 것 → H2 제작 절차와 기간 → H2 포트폴리오(실제 사례) → H2 요금 → H2 FAQ

### ④ 업종별 랜딩: "병원 홈페이지 제작"

- **타깃**: 병원 홈페이지 제작 (320, KD 30)
- 의료법 광고 심의, 예약, 진료시간처럼 업종 특화 내용으로 차별화한다. 사례가 생기면 학원·카페·법률사무소 등으로 확장한다.

### ⑤ 가이드 글: "도메인 연결 방법"

- **타깃**: 도메인 연결(90), 도메인 설정(50). 둘 다 KD 0.
- PW Studio의 "독립 도메인 세팅" 서비스와 바로 이어진다. 가비아·후이즈·Cloudflare별 DNS 설정 방법을 단계별로 정리하고, 마지막에 "대신 세팅해 드립니다"로 행동을 유도한다.

## 4. 실행 순서

1. ① 가격 페이지 (KD 0, 구매 의도)
2. ② 가이드 글, ⑤ 도메인 가이드
3. ④ 업종별 랜딩 1개
4. ③ 기업 홈페이지 랜딩 (포트폴리오 확보 후)
5. 병행: 네이버 서치어드바이저 등록과 사이트맵 제출 (Google 외 수요 확보)

## 5. 성과 확인

- GSC: 게시 후 4주·8주 시점에 페이지별 노출, 클릭, 평균 순위를 확인한다(현재 노출 0).
- OpenSEO: 월 1회 `get_ranked_keywords target=pwstudio.kr` 재조회(현재 0개).
- 네이버: 서치어드바이저의 검색 유입 보고서를 함께 본다(OpenSEO 미지원).
