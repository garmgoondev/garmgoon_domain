# EverydayTutor (`everydaytutor.net`) 테크니컬 SEO 오디트 리포트

- **대상 사이트**: EverydayTutor (`https://www.everydaytutor.net`)
- **작성일**: 2026-10-05
- **데이터 출처**: OpenSEO Site Audit Crawler (50개 페이지 전수 크롤링) & HTTP 실시간 응답
- **크롤링 지표**: 크롤링 페이지 50개, 평균 응답속도 674ms, 발견된 이슈 60건 (Warning 18건, Info 42건)
- **분석 한계**: 크롤러 페이지 예산 50페이지 기준이며, 대만 로컬 검색 엔진 최적화 관점에서 진단함.

---

## 1. 종합 진단 요약

EverydayTutor는 과목별/지역별 계층 구조(`/tutors/[city]/[subject]`)와 시장 인사이트 콘텐츠(`/insights/...`)가 체계적으로 구축되어 있어 검색 엔진 색인 기반이 우수합니다.
다만, 38개 이상의 페이지에서 **메타 설명문이 너무 짧거나 누락**되어 있고, 개별 구인/구직 포스트(`/posts/...`)의 본문 분량이 적어 씬 콘텐츠(Thin Content)로 분류되는 현상이 확인되었습니다. 또한 일부 데이터 조회 페이지의 응답 시간이 1.5초를 초과하여 서버 렌더링 최적화가 필요합니다.

---

## 2. Action Items 및 권장 수정 방법

### [P1] 지역/과목 랜딩 페이지 메타 설명문 템플릿화 (38개 페이지)

- **영향받는 URL**:
  - `/tutors/taipei/english`, `/tutors/taipei/mathematics`, `/tutors/new-taipei/english` 등 지역/과목 38개 페이지
- **문제 근거**: 메타 설명문이 없거나 20~30자 이내의 짧은 문장으로 되어 있어 SERP에서 사용자의 검색 의도를 충분히 충족시키지 못함. (현재 GSC 66회 노출 대비 CTR 1.5%의 주원인)
- **SEO 영향**: 검색 스니펫 매력도 저하로 인한 클릭률(CTR) 손실.
- **권장 수정 방법**:
  - 도시 및 과목 데이터를 조합한 동적 메타 디스크립션 템플릿 적용 (약 120~140자):
    - 템플릿: `【{城市}{科目}家教推薦】每日家教精選 {城市} 優質{科目}老師，涵蓋國小、國中、高中升學與檢定輔導。即時查看師資履歷、家教時薪行情與學生評價，免費在線預約試教！`
    - 예시 (`/tutors/taipei/english`): `【台北英文家教推薦】每日家教精選台北優質英文老師，涵蓋國小、國中、高中學測指考與成人英語。即時查看時薪行情與真實評價，免費線上預約試教！`
- **수정 후 확인 방법**: OpenSEO 재오디트 시 'Meta description too short' 경고 0건 확인 및 GSC CTR 변화 추적.

### [P2] 단문 게시글(`/posts/...`) 씬 콘텐츠(Thin Content) 방지 구조 개선

- **영향받는 URL**: `/posts/100000004`, `/posts/100000005`, `/posts/100000006`, `/posts/100000007` 등 (단어 수: 17~43개)
- **문제 근거**: 교사 또는 학생이 등록한 한두 줄의 텍스트만 렌더링되어 페이지 전체 본문 단어 수가 50단어 미만으로 극히 적음.
- **SEO 영향**: 검색 로봇이 품질 낮은 자동 생성형 페이지로 인식하여 크롤링 인덱싱에서 제외하거나 페널티를 부여할 수 있음.
- **권장 수정 방법**:
  - 게시물 본문 외에 교사 프로필 템플릿, 지도 가능 과목, 학력/경력 정보, 수업 진행 방식 등 구조화된 스키마/요약 카드를 기본 렌더링하도록 템플릿 보강.
  - 관련 지역 추천 교사 목록(Related Tutors) 3~5개를 본문 하단에 함께 노출하여 페이지 내 유효 텍스트 볼륨을 300단어 이상으로 확보.
- **수정 후 확인 방법**: OpenSEO 재오디트 시 'Thin content' 경고 해소 확인.

### [P2] TTFB 및 SSR 응답 속도 최적화 (2개 페이지)

- **영향받는 URL**:
  - `/insights/taipei-english-tutor-rates` (1,682ms)
  - `/posts/100000008` (1,575ms)
- **문제 근거**: 서버 응답 시간(TTFB)이 1.5초를 초과하여 OpenSEO에서 'Slow server response' 경고 발생.
- **SEO 영향**: Google의 Core Web Vitals (LCP) 지표 하락 및 검색 랭킹 불이익.
- **권장 수정 방법**:
  - 인사이트 리포트 및 통계 페이지의 쿼리 결과에 대해 Cloudflare KV 또는 Edge Cache(SWR: `stale-while-revalidate`)를 1시간~24시간 적용하여 캐시 히트 시 100ms 이내로 즉각 응답하도록 개선.
- **수정 후 확인 방법**: OpenSEO 재오디트 시 평균 응답속도 300ms 이내 달성 확인.
